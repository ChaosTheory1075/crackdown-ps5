Put Crackdown's files here (this is PPSA53070/game/):

- Everything from the disc: default.xex (the disc may call it Default.xex -
  either is fine), the .dff files, Audio/, Local/, Streaming/ and the rest.
- Default.xexp from Title Update 6 (TU_16L61US_0000004000000.00000000001G1),
  next to default.xex.
- The update's other files (Local/<language>/GameStrings_DLC.str) in
  game/update/, so this folder has update/Local/en-US/... and so on.

DLC (optional): each package (Free-For-All Pack, Four-Play Pack), extracted
into a folder named as the package, in ../dlc/ (install_to_ps5.ps1 does this).

The menu's HOME page says what it found when the app starts.
